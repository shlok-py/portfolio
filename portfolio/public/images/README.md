# Portfolio assets

Place public-facing media here so it can be referenced from the locale data and components.

- `projects/`: project screenshots or product images. The project tour currently expects:
  - `projects/sanjyaan.webp`
  - `projects/shades-of-history.webp`
  - `projects/abstractive-qa.webp`
  - `projects/chandaparser.webp`
- `experience/`: company, lab, or role images when CV-backed experience is added.
- `documents/`: public PDFs such as a resume or case studies.

Files in `public/` are referenced from the site root. For example, `public/images/projects/sanjyaan.webp` is used as `/images/projects/sanjyaan.webp` in the locale data.
